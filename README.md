# -Experiment_1_Python_ML_Environment_Basics

Experiment 1: Python and ML Environment Basics
Objective

This experiment introduces the basic Python libraries and tools commonly used in Machine Learning. It covers NumPy for numerical calculations and Pandas for data manipulation and analysis.

Assignments
Assignment 1: NumPy Statistics

Create a NumPy array containing the internal marks of 10 students and calculate:

Mean
Median
Standard deviation
Maximum value
Minimum value
Assignment 2: Pandas DataFrame

Create a Pandas DataFrame containing:

Student Name
Roll Number
Marks
Attendance

Filter and display students who have scored above 80 marks.

Assignment 3: Dynamic Grade Calculation

Add a dynamically calculated Grade column to the DataFrame based on the student's marks.

The grading criteria used are:

Marks	Grade
90–100	A
80–89	B
70–79	C
60–69	D
Below 60	F
Technologies Used
Python
NumPy
Pandas
How to Run

Install the required libraries:

pip install -r requirements.txt


Then run each assignment separately:

python Assignment_1_NumPy_Statistics/assignment_1.py

python Assignment_2_Pandas_DataFrame/assignment_2.py

python Assignment_3_Student_Grades/assignment_3.py

Conclusion

This experiment provides hands-on practice with NumPy arrays, statistical calculations, Pandas DataFrames, filtering data, and dynamically creating new columns from existing data.
